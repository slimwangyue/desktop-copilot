# Desktop Copilot（测试版）

装在自己电脑上的 AI 工具商店：说一句你想做什么，它帮你找到合适的开源工具，一键装好，在你的显卡上运行。文件不上传，模型也在本机。

## 能做什么

- **视频配字幕并翻译**：拖一个视频或贴一个链接，生成中英双语字幕，可以直接烧进视频。
- **工具商店**：语音转文字、文字转语音、截图识字、抠图、画图、老照片修复、人声分离、文档转换、PDF 翻译、按内容搜照片和文档等，点一下就装，不用自己配环境。
- **说需求就行**：在首页输入框里说「把这段录音转成文字」，助手会选工具、装好、跑完，把结果给你。列表里没有的，它会去 GitHub 找开源程序，核对许可证和下载校验值后再问你要不要用。
- **看得懂你的电脑**：每个工具卡片会写这台电脑跑它要多久；以后还会显示同型号显卡上其他人的实测结果。
- **不打扰游戏**：检测到你在玩游戏时，要用显卡的工具会等你玩完。

## 下载安装

到 [Releases](../../releases/latest) 下载最新的 `DesktopCopilot-vX.Y.Z-x64-setup.exe`，双击安装。

- 装在当前用户下，不需要管理员权限。
- 第一次打开时会检测显卡和内存，推荐合适的模型，然后下载所需组件。模型从约 7 GB 起，放在剩余空间最多的磁盘，可以修改。
- 工具按需安装，每个工具的大小写在卡片上。

### 电脑要求

- Windows 10 / 11，64 位
- NVIDIA 显卡，8 GB 显存或以上（8 GB 能用，12 GB 以上更快）
- 16 GB 内存或以上
- 至少 20 GB 可用磁盘空间（模型和工具越多需要越多）
- 安装时需要能访问 GitHub 和 Hugging Face（国内会自动尝试 ModelScope 下载模型）

### 校验下载

每个安装包旁边都有 `.sha256` 文件，可以在 PowerShell 里核对：

```powershell
Get-FileHash .\DesktopCopilot-vX.Y.Z-x64-setup.exe -Algorithm SHA256
```

### Windows 提示「无法识别的应用」

安装包目前还没有代码签名，Windows SmartScreen 会提示风险。确认是从本页下载、校验值一致后，点「更多信息」→「仍要运行」。

## 隐私

- 你的文件、对话和屏幕内容只在你的电脑上处理。
- 「运行数据」（哪个工具、用了多久、成没成功、显卡型号）默认不发送；第一次用工具后会问你一次，可以随时在设置里关掉。
- 分享工具配方、提交反馈之前，都会先把要发送的内容完整给你看。

## 反馈

测试版一定有问题。在应用的「设置 → 通用 → 反馈问题」里写下发生了什么，可以附上诊断信息（先给你看，不含对话、文件名和路径），然后在 GitHub 上提交。也可以直接提 [Issue](../../issues)。

## 卸载

在「设置 → 应用」里卸载 Desktop Copilot。卸载时会保留这些，方便以后重装或升级时接着用：

- 已下载的模型和工具（体积较大）
- 你的设置、项目和对话状态，存在 `%LOCALAPPDATA%\DesktopCopilot\kept-state`

不再需要的话，可以手动删除整个 `%LOCALAPPDATA%\DesktopCopilot` 文件夹，以及模型所在的文件夹。

## 升级

应用会在有新版本时提示你；也可以下载新版本的安装包直接安装。你的设置、项目和对话会保留。

## 第三方组件

安装时从各项目的官方来源下载开源组件的固定版本，各自遵循其许可证；具体版本见每个 Release 的说明，每个工具的来源和许可证写在它的卡片上。

- [Hermes Agent](https://github.com/NousResearch/hermes-agent)（MIT）
- [llama.cpp](https://github.com/ggml-org/llama.cpp)（MIT）
- [Strata](https://github.com/Niko1221/Strata)（MIT；模型有各自的许可证）
- [uv](https://github.com/astral-sh/uv)（MIT 或 Apache-2.0）

本仓库只用于发布安装包和共享工具目录（`registry` 分支），不包含源代码。
